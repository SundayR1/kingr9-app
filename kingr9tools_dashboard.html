เปิดโฟลเดอร์ข้อมูลของแอป — licenses · config · log · registry backups · สคริปต์ R9 ทั้งหมด

🚀 เริ่มต้นใช้งานใน 4 ขั้นตอน

1
รับ key จากแอดมินรูปแบบ KING-XXXX-XXXX-XXXX — ส่งกันทางแชท
2
เปิดโปรแกรม ใส่ key หน้า Activateพิมพ์ key ให้ถูกต้อง แล้วกดปุ่ม Activate
3
ระบบล็อค key กับเครื่องนี้ให้อัตโนมัติkey หนึ่งตัวใช้ได้เครื่องเดียว (ผูกกับ HWID ของเครื่องแรกที่ Activate)
4
ใช้งานได้ทุกเมนูจนกว่า key จะหมดอายุครั้งถัดไปเปิดโปรแกรมจะเข้าให้อัตโนมัติ ไม่ต้องกรอก key ซ้ำ

🛠 แก้ปัญหาที่เจอบ่อย

"key นี้ถูกผูกกับเครื่องอื่นอยู่"key ถูก Activate ที่เครื่องอื่นแล้ว → แจ้งแอดมินขอรี HWID แล้ว Activate ใหม่
"key ถูกระงับการใช้งาน"โดนระงับจากฝั่งแอดมิน → ติดต่อแอดมินเพื่อตรวจสอบ/ปลดระงับ
"key หมดอายุการใช้งาน"ครบกำหนดแพ็กเกจ → ต่ออายุกับแอดมิน (ใช้ key เดิมได้ทันที ไม่ต้องขอใหม่)
เปลี่ยนเครื่อง / ลง Windows ใหม่HWID จะเปลี่ยน → แจ้งแอดมินรี HWID แล้ว Activate ใหม่ได้ปกติ
เน็ตหลุดชั่วคราวใช้งานต่อได้ตามปกติ — ระบบจะตรวจกับ server ใหม่เองเมื่อเน็ตกลับมา

⚠️ ข้อควรรู้

🔑 1 key = 1 เครื่อง — ล็อคกับเครื่องแรกที่ Activate อัตโนมัติ เครื่องอื่นเอาไปใช้ไม่ได้

🚫 ห้ามแชร์ / ขายต่อ key — ทุกการเข้าใช้งานถูกบันทึกประวัติฝั่งแอดมิน ถ้าโดนระงับ key จะเข้าไม่ได้ทุกเครื่อง

🚪 ปุ่ม Logout = ออกจากบัญชี — เปิดโปรแกรมครั้งถัดไปต้องใส่ key ใหม่อีกครั้ง
